### 今日问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| JMeter 断言全失败 | `test_field` 为空默认检查 URL | 改用 **JSR223 + Groovy** 断言 JSON |
| JSR223 JSON 解析乱码 | Windows 编码问题 | 改用 `ByteArrayInputStream` 代替 `getResponseDataAsString()` |
| Gitee push 失败 | 仓库包含 650MB 的 IDE 安装包 | `git filter-branch` 清理历史 + `--force` 推送 |
| 终端中文乱码 | Windows GBK vs UTF-8 | 已全部改为英文日志 |
