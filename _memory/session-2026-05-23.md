**2. 滑块验证码稳定性优化**（`ui/pages/login_page.py`）
- 拖动从 50 步增至 100 步，加入随机间隔

**3. admin 后台认证流程解密**
- 初次访问商品分类接口返回 403
- 尝试 admin 登录 → 依然 403
- 发现登录参数需加 `"captcha": true`
- 且登录后必须依次调用 3 个接口加载权限上下文：
  - `GET /admin/system/user/info`
  - `GET /admin/system/menu/permissions`
  - `GET /admin/system/menu/route-menu`
- ✅ `backend_token` fixture 已封装完整流程
